# 研究设计

## 研究问题

本项目研究数值答案验证器怎样改变可验证奖励强化学习（RLVR）的训练信号，以及这种变化是否反映到最终答案正确率上。重点观察一类可明确识别的错奖。回答在正文写出标准答案的数值，最后答错，全文数值匹配仍给正确性奖励。

GRPO 按同题回答的相对得分计算优势。一个组如果有四条错答、四条都被误奖且格式得分相同，四条的优势起初都是零。撤回其中一笔奖励，另外三条错答就会得到正优势。在线实验检验的是，控制实际撤奖次数后，把纠错机会用在已有正确回答的组，还是用在全错组，会让训练后的模型答对更多题。

## 对照条件

| 条件 | 起点 | 处理 |
|---|---|---|
| E0 | Qwen2.5-0.5B-Instruct | 历史贪心评测，直接评估初始模型。 |
| E1 | 指令微调模型 | 从 GSM8K 取示范做 LoRA SFT，仅对回答计算损失。 |
| E2 | 合并 E1 adapter 后的模型 | 训练独立 LoRA adapter，以严格末答判定给正确性奖励。 |
| E3 | 与 E2 相同的合并 E1 | 用全文数值匹配给正确性奖励。 |
| E4 | 与 E2 相同的合并 E1 | 在同题、同格式得分的严格失败回答间重分配宽松奖励。 |
| E5 | 同一个 1.5B E1 | 比较两种限额纠错策略，同时运行原宽松规则和最终答案优先规则。 |

E2 与 E3 配对控制数据、步数、采样和格式奖励，共用合并后的 E1 作为 KL 参考策略。E4 在每组保留总奖励分布，让该组原有的奖励可以落到其他回答上。早期 Qwen2.5-0.5B-Instruct 的历史结果包括单种子贪心测试、300 步开发集探索和后续三种子的分组采样审计。1.5B 基线从新的 1.5B E1 出发，E2–E4 各用种子 44 训练 100 步。两批实验采用各自的评测口径，结果分别查看。 [历史单卡结果](results/single-gpu-baseline.md) · [当前结果概览](../README.md#研究问题与实验进展)

## E5 的撤奖配对

先用同一个 1.5B E1 在两批训练题上生成回答。其中一批是随机抽取后筛查保留的 108 道题，另一批是先前轨迹中观察到宽松错奖的 24 道题。两批题的回答用于筛选这轮在线训练的 35 道题。冻结测试题只用于最后评估。 [独立采样配置](../configs/gsm8k-1.5b-reward-repair/random-panel.json) · [定向采样配置](../configs/gsm8k-1.5b-reward-repair/enriched-panel.json) · [训练配置](../configs/gsm8k-1.5b-reward-repair/repair.json)

两种限额策略均要求一个组的四个回答完整、格式合规且最终答案能明确判定，并且至少有一笔错奖。全错策略只对四条都错的组撤奖，有对有错策略只处理组内同时出现正确和错误答案的情况。每次在符合条件的被误奖回答中随机选择一条，将正确性奖励从 1 改为 0。同一道题在一次训练中最多撤一笔。

每个种子先运行全错策略，再根据实际审计记录，为有对有错策略设置每 25 个优化步的撤奖上限。种子 47 的实际预算是 2、4、3、2，种子 48 是 3、4、3、1。两种策略在每个种子里都实际撤了 11 笔。两者撤奖发生的具体题目和优化步有差别。原宽松对照保留原评分。最终答案优先对照优先使用可解析的数值标签，无法解析时使用宽松规则。 [奖励回调](../src/verifierlab/repair_policy.py) · [计划生成](../src/verifierlab/reproduce.py)

## 评测与固定回答分析

GSM8K 官方训练集提供相互隔离的 SFT、GRPO 和开发集。准备过程按规范化后的题面做精确去重，记录分片身份，并在当前完整实验中根据审计配置排除有疑问的官方测试题。1.5B 的 E1–E5 都在同一批 200 道冻结测试题上每题采样四个回答，统一按显式最终答案的正确性计分，分母包含未能判定的回答。配对 bootstrap 以测试题为单位重采样。E5 的区间描述当前两个固定训练种子的题目层不确定性。 [测试集审计配置](../configs/gsm8k_test_audit.json) · [评测对照](../src/verifierlab/repair_study.py)

固定回答实验先比较两种规则给同一批输出的奖励，再测量撤奖对局部 LoRA 梯度的影响。参考梯度用最终答案正确性和格式奖励计算。对同一组的每个单笔撤奖候选分别计算与参考梯度的距离，再取平均。整组与逐笔纠错比较还固定每笔候选被撤回的概率。在 20 个多错奖组的离线比较中，各方式撤回 17 笔，整组纠错的平均局部梯度距离低约 26%。该结果来自冻结策略和固定回答，整组纠错的在线训练效果有待验证。 [梯度探测](../src/verifierlab/repair_gradient.py) · [预算分配回放](../src/verifierlab/repair_allocation.py)
