# 研究设计

## 研究问题

本项目研究数值答案验证器如何改变可验证奖励强化学习（RLVR）的奖励信号，以及这种变化如何影响模型的最终答案表现。宽松规则能为正文中出现正确数值的回答给分。错误答案、缺少答案标签以及表达式片段都可能产生这种分歧。

研究分两步检验这一机制。首先，对同一 E1 策略的开发集采样同时计算两种奖励，观察误判和组内奖励差异。随后，从同一 E1 独立训练 strict 和 weak 两个 GRPO 条件，用统一评测比较两者。学习到的策略是否系统性地利用宽松规则，是需要用后续受控实验验证的假设。

## 对照条件

| 条件 | 起点 | 处理 |
|---|---|---|
| E0 | 固定的 Qwen2.5-0.5B-Instruct | 直接生成并评测。 |
| E1 | 同一基座模型 | 使用 GSM8K 示范进行仅对回答计算损失的 LoRA SFT。 |
| E2 | 合并 E1 adapter 后的模型 | 训练新的 LoRA adapter，以 strict 判定作为正确性奖励。 |
| E3 | 与 E2 相同的合并 E1 | 训练独立的 LoRA adapter，以 weak 判定作为正确性奖励。 |

E0 与 E1 的对照测量 SFT 后的变化。E1 与 E2、E3 的对照测量各自 GRPO 训练后的变化。E2 与 E3 的主对照固定数据、初始化、参考策略、训练预算、采样、格式奖励、数值等价规则和评测口径，仅切换正确性奖励的候选选取规则。E2 与 E3 共用合并后的 E1 作为 KL 参考策略。

## 数据与评测

GSM8K 官方训练集提供相互隔离的 SFT、GRPO 和开发集，官方测试集提供最终评测题。题目按空白折叠和大小写折叠后的精确内容去重，官方测试题优先保留。划分使用固定的 seed 42，并通过 manifest 记录样本身份和数据内容。精确去重的覆盖范围是规范化后的相同题目；改写题和预训练污染需要额外审计。

开发集用于训练监控、weak 审计及预算探索。测试集用于评估事先确定的 checkpoint。所有条件使用同一提示词、同一题序和同一贪心解码配置，每题生成一个回答，最多生成 512 个新 token。严格正确率衡量符合答案标签约定的数值正确性，格式率衡量输出契约的遵守情况。弱验证分歧、截断和回答长度用于解释分数变化。

配对比较以题目为单位，报告差值、配对 bootstrap 区间和适用的 McNemar 检验。单种子的区间刻画固定样本上的配对差异。机制分析结合正文命中、错误末答、格式缺失、题干数字复用、奖励方差和 KL 诊断。系统性利用的判断需要额外的逐样本证据与跨种子重复。

100 步测试集对照和 300 步开发集探索各自保留。300 步运行从同一 E1 重新开始，步数预算同时改变学习率衰减的跨度。下一轮研究拟加入独立于答案标签的内容正确性指标，并用成对种子复核结论。现有测量见[单卡实验结果](results/single-gpu-baseline.md)。
